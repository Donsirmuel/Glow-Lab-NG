# Glow Lab NG — Skincare Clinic Landing Page

Lead-generation landing page for **Glow Lab NG**, a Lekki, Lagos skincare clinic focused on clear melanin-rich skin without bleaching.

## Run Locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
4. Type-check:
   ```bash
   npm run lint
   ```
